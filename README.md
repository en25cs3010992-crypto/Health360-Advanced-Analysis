# Health360: Advanced Healthcare Risk Analysis

## Project Overview
This data analytics project analyzes 5,000 patient records to identify risk factors for chronic diseases. The dashboard features custom data binning to evaluate health outcomes based on demographic and lifestyle variables.

## Key Features
* Custom calculated fields grouping patients by BMI Category (Underweight to Obese) and Age Brackets.
* Advanced interactive Tableau dashboard featuring health risk distributions, disease prevalence by smoking status, and exercise level tracking.
* Dataset: `smart_healthcare_dataset.csv`
